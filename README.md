# Todo list
Это мой первый проект Todo List.
## Демо
https://kioshi-1.github.io/todo_list/
## Функционал
Можно добавлять задачи, отмечать их выполненными и удалять.
Кнопка "Выполнено" переключает статус выполнения (зачеркивание текста). Кнопка "Удалить" полностью удаляет задачу.
## Стек
Данный проект написан на html, css и js.
